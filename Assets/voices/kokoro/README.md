# Narration voices (Kokoro)

Michael (`am_michael`) and Bella (`af_bella`) from Kokoro v1.0, for narrating videos.

    ./setup.sh
    python3 say.py michael "What if every minute added ten degrees?" line.wav

`voices-michael-bella.npz` holds the two voices. The model is downloaded by `setup.sh`, which checks its checksum. Listen to `samples/` to compare the voices.
